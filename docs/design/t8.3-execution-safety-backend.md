# T8.3 execution-safety backend disposition

**Status:** decided 2026-08-02 (interim)  
**Target:** 🎯T8.3

## Product goal

Fleet worker (jwork) spawn of release-class / high-risk actions is
**risk-graded**, **observable**, and **not** “provider `--always-approve`
for everything” with no gate.

## Options considered

| Backend | Fit | Notes |
|---------|-----|--------|
| **doit** (`github.com/marcelocantos/doit`) | Spawn-time policy Evaluate/Execute, L1/L2 chain, capability registry, hash-chained audit | Semi-deprecated as a product, but **shipped** and already on the jwork path |
| **writ** (`github.com/marcelocantos/writ`) | OS-level intent sandbox (seatbelt/Landlock): command only runs inside a declared FS/net world | Preferred long-term enforcer; **different model** (manifest-first `writ exec`), not a drop-in for “evaluate task text before spawn” |
| None | — | Rejected — leaves T6 post-MVP hole open |

## Decision (intentional, not silent absorption)

1. **Interim engine: doit**, wired under `internal/doit` and
   `jwork` `GateSpawn` + `structuredContent.policy` metadata
   (decision/level/reason/rule_id/audit_seq).
2. **Preferred successor: writ** — thin vertical landed under 🎯T335
   (`internal/writconf` + `internal/secauditor`,
   `POST /api/security/confined-exec`, `jevons_writ_exec`). Compiles a
   fleet manifest and runs under writ seatbelt/egress; undeclared net
   denied; security auditor alerts overseer. Residual: full Bash cutover
   of every provider-side tool.
3. **Why not writ-only today:** writ needs a manifest and a child
   exec path rewrite; jwork still spawns Grok ACP workers whose
   in-session Bash is provider-side. Doit gates the **spawn/task text**
   and records audit; it does not claim to sandbox every Grok Bash
   call. Residual is documented on the target.

## Oracle evidence (landed)

- `go test ./internal/doit` — Open, L1 deny catastrophic task, allow normal task, audit chain
- `go test ./internal/mcpserver -run TestHandleJworkPolicy` — jwork returns policy metadata / deny path
- Product commit family: `0cc5720` (+ workers panel `f56f214`)

## Non-goals this slice

- Replacing Grok `--always-approve` for every tool call
- Full L3 LLM gatekeeper on by default
- Eliminating doit from go.mod before writ is wired
