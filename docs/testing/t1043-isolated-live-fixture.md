# 🎯T1043 isolated LIVE fixture: safety boundary (not yet a LIVE oracle)

The persisted-census oracle in `internal/mcpserver/t1043_process_census_test.go` creates 130 parked rows and verifies admission after liveness expiry. It does not launch a process. `cmd/jevonsd/t1043_live_fixture_test.go` preflights isolated paths and refuses to boot even with its opt-in flag. Neither test meets the target's LIVE criterion.

A proposed next slice must use **one throwaway daemon** for the entire assertion: persist 130 parked definitions and durable parked intents before boot; observe its own census/admission through the production `jevons_agent_start` path; capture the fixture provider process PID and prove that PID is alive while the daemon reports the seat running; confirm parked rows still exist and do not contribute to the cap. A synthetic registry `Launch` plus an unrelated child PID is not sufficient. The test must not claim an LLM completed a turn: a fake provider handshake proves only a process mint.

Before replacing the deliberate `Skip`:

1. Audit every startup loop and shell operation in `cmd/jevonsd/main.go`, plus Claudia broker and sidecar startup at the pinned module version. Disable or stub all ambient effects, including overseer auto-start, idle nudges, sentinel, RSI coach, research, auditor, port ownership, launchctl and reattach. `frontier_consume.disabled` alone does **not** do that. Explicitly fail closed if the fake provider protocol changes; never fall through to a real CLI or credential.
2. Use a temp `HOME`, `XDG_STATE_HOME`, state directory, session/transcript directory, isolated short Claudia broker/OMP/tmux Unix sockets, fake `security` and provider binaries, and an ephemeral 127.0.0.1 listener. No request or side effect may reach `:13705`, `~/.jevons`, the development broker socket, Keychain, launchctl or real tokens. Ensure all provider credential acquisition is satisfied by fixture-only material and network egress is refused.
3. Arm `internal/testreap.Arm` **before** starting children so a Go test timeout or SIGKILL also sweeps detached sidecars. Put daemon/broker in process groups, use bounded contexts and timers for startup/handshake/API/shutdown, and verify no fixture PIDs remain after cleanup. A socket created under the temp root but started without a temp-root argv marker evades this reaper; enumerate that case explicitly.
4. Probe the same daemon API that launched the fixture worker; save response, PID, census and registry path as oracle evidence. Assert 130 parked + 1 live, admission under cap 100, and actual process liveness; check host-pressure guard still refuses when it should. A memory-pressure refusal is **not** license to change owner `memory_gate_off=false`.
5. Only then run the opt-in under `bin/gate -clean -- ...` after committing the fixture. Never run a broad `go test ./...` to discover whether it is safe. Keep 🎯T1043 open until independently reviewed LIVE evidence exists.

The T627 and T884 daemon fixtures illustrate broker/socket setup but are unconditionally skipped for their old fake sidecar providers, and their full daemon boots do not establish all of the confinement requirements above. Copying them as-is would turn an opt-in test into a real-fleet incident.
